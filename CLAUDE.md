# CLAUDE.md

Context for working in this repo — a personal meal-planning reference library, not a fixed weekly plan. See `README.md` for the file layout.

## Dietary framework
- Low-carb-ish, whole-food-first — no processed substitutes (e.g. mashed avocado instead of a dairy-free cream cheese product)
- No red meat, no processed snacks
- Dairy swapped for whole foods (olives, avocado, walnuts, coconut milk) — see `reference/whole-food-swaps.md`
- Onion/garlic cloves avoided by default (garlic-infused oil, scallion greens instead) as a bloat-trigger precaution — see `reference/bloat-triggers.md`. These are defaults, not hard rules; swap back in freely if they're not actually an issue.
- Occasional exceptions are fine (e.g. sweet potato) when that's what's on hand from leftovers — flag it as an exception rather than rewriting the framework around it.

## Shopping
Primary store is ALDI; `reference/aldi-shopping-list.md` has the categorized template. Some items (whole turkey breast, tahini, coconut aminos) are unreliable there — check `whole-food-swaps.md` for what to substitute or pick up elsewhere.

## Recipes
One file per dish in `recipes/`, format: `**Serves:** · **Time:** · **Type:**`, then Ingredients / Steps / Notes. When adding a new recipe (e.g. from a leftovers improvisation), follow this format and note what it's built to use up.

## Journal
`journal.md` is newest-entry-first. Log what was actually cooked, day-of adjustments (eating out, packed snacks, leftovers repurposed), and anything picked out for the coming days. Not a place for the full framework — that lives in `reference/`.

## Batch prep
Budget roughly double the time a batch session looks like on paper, even split across two people — see `reference/batch-prep-notes.md` before suggesting a big multi-component prep day.
