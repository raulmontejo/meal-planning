# Meal Planning

A reference library for whole-food, low-carb, batch-friendly cooking — built to pull individual pieces from rather than follow as a rigid weekly plan.

## Layout

- `recipes/` — one file per dish. Ingredients, steps, rough time, make-ahead notes.
- `reference/` — cross-cutting notes that apply across recipes:
  - `whole-food-swaps.md` — dairy, red-meat, and processed-snack swaps, plus what's reliably at ALDI
  - `bloat-triggers.md` — foods that commonly cause bloating and how this plan avoids them
  - `batch-prep-notes.md` — what holds up as a make-ahead batch vs. what to cook fresh, and realistic timing
  - `aldi-shopping-list.md` — a categorized checklist template, split into an ALDI run and a second-stop list
- `journal.md` — running log of what we actually cooked, what worked, what didn't. Add to it as you go.

## How to use this

Pick a handful of recipes for the week rather than trying to run the whole set — see `journal.md` for what's currently in rotation. `batch-prep-notes.md` has the honest timing (double whatever a recipe says, even split across two people) so you can scope how much prep actually fits.
